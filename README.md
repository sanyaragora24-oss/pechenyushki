# Печенюшки от Танюшки — сайт

Статический сайт без сборки и серверной части: `index.html`, страница QR `qr.html`, картинки в `img/`, библиотека QR в `js/`.

## Публикация на Cloudflare Pages (бесплатно, ~2 минуты)

1. Войти на https://dash.cloudflare.com (бесплатный аккаунт).
2. **Workers & Pages → Create → Pages → Upload assets** (Direct Upload).
3. Имя проекта: `pechenyushki`. Перетащить **содержимое этой папки** (файл `index.html` должен оказаться в корне, не во вложенной папке).
4. **Deploy**. Адрес будет `https://pechenyushki.pages.dev` (если имя занято — Cloudflare предложит другое, см. ниже).

### Если адрес получился другим
В `index.html` в начале есть 4 строки с `https://pechenyushki.pages.dev` (canonical, og:url, og:image). Замените адрес на свой — это нужно только для красивого превью ссылки в мессенджерах. Сайт работает и без замены.

## Настройки (index.html → блок `CONFIG`)

```js
PHONE: '+79224601116',
MAX_URL: '',   // профиль Татьяны в MAX
VK_URL: '',    // ВКонтакте
WHATSAPP: true,
MIN_DAYS: 5,
RECIPE: { composition: '', allergens: '', storage: '' }
```
Пустая ссылка — кнопка не показывается. Как только вставить ссылку MAX или ВК, появятся кнопки в форме заказа, в контактах и в нижней панели.
`RECIPE` — точный состав, аллергены и хранение. Пока пусто, на сайте написано «уточняется у Татьяны». Заполнять только после проверки рецептуры.

## QR-коды и наклейки

После публикации откройте `https://<адрес>/qr.html`:
- **QR №1 — Главный** → главная страница.
- **QR №2 — Волшебный пряник** → `/#privet`, сразу к говорящему прянику.

Страница сама подставит адрес сайта, построит коды и наклейки. Скачивание включается только после галочки «отсканировал телефоном». Файлы: наклейка PNG 1200×1500, QR SVG (вектор для типографии), QR PNG 2048×2048.

**Не печатайте QR на ссылку Claude Artifact** — она закрыта для покупателей.

## Что заменить, когда будут материалы

- Фото наборов: положить в `img/` с теми же именами (`box.webp`, `round.webp`, `detki.webp`, `cards.webp`, `girl.webp`, `hero.webp`) и убрать пометки «Иллюстрация» (класс `illus` в index.html и строку «Изображения на сайте — иллюстрации…»).
- Иллюстрации мастерской помечены «временная иллюстрация».
- Текст «О мастере» — проверить с Татьяной.

## Озвучка пряника

Голос — готовые MP3 в `audio/` (18 файлов: `s<история>-<фраза>.mp3`, `ing-<ингредиент>.mp3`), играют через обычный `<audio>` по нажатию «Слушать». Синтез речи телефона — только резерв, если файл не загрузился.
`audio/env.json` — профиль громкости каждой записи для анимации рта (25 кадров/с).

Если поменяли текст фразы в `index.html` — перегенерируйте её запись и профиль (скрипты в `Projects\pechenyushki\tts`: `gen2.mjs`, голос ru-RU-SvetlanaNeural) или запишите голос Татьяны и положите MP3 с тем же именем.
